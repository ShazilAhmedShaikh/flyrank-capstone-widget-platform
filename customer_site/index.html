Testing Cross-Origin Embeddable Widget

This webpage simulates a customer website running on a completely distinct origin (e.g. http://localhost:5500 or file://). The backend API runs on http://localhost:8000.

The lead capture widget below was installed with exactly one single line of HTML:

<script src="http://localhost:8000/widget.js?id=widget-demo-newsletter" async></script>

When you submit the form in the bottom right corner, your browser sends a cross-origin POST request with CORS headers, triggers abuse rate limits, undergoes honeypot checks, performs IP geolocation enrichment via fallback chain, and records the lead safely in the backend.
